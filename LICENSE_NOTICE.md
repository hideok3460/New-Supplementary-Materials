# Rights and privacy review; not a license grant

This repository alignment does not choose a license or grant new rights on behalf
of the authors. Existing notices inside the original hardware archive remain
unchanged. Public visibility is not a blanket license to reuse every file.

The main submitted article, reviewer replies, private editorial records,
RightsLink permission/billing documents and original conference paper are not
included by this update. Do not add them automatically just because the target
submission ZIP contains them or because figure reuse in a journal was permitted.
Any later publication of additional material needs its own author/rights review.

The preserved research archive includes real job identifiers and historical
software logs that may contain local-user paths. Review those before publication.
API keys, passwords, cloud-account files, `.qiskit`, `.venv`, and private emails
must not be added. A `.gitignore` file cannot inspect the inside of a ZIP.

Decide any appropriate code/data/document license with the rights holders.
If the existing live repository has a license, retain and review it; the small
update does not delete an unlisted LICENSE file or override its legal effect.
